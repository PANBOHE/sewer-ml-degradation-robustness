# sewer-ml-degradation-robustness



Code and configurations for "Multi-label sewer defect recognition under
controlled image degradation: recovery and error trade-offs" (submitted to
J. Electron. Imag.).

Status: pre-release. The generation code, frozen configurations, seeds,
thresholds and aggregate outcome tables are supplied to editors and reviewers
as Supplement 2 with the manuscript. A public release is planned after
acceptance. Please contact the corresponding author for earlier access.
