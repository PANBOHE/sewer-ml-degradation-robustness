# sewer-ml-degradation-robustness

Code and configurations for the manuscript **"Multi-label sewer defect recognition under
controlled image degradation: recovery and error trade-offs"**, submitted to
*Journal of Electronic Imaging* (SPIE).

## Status: pre-release

The public release of this repository is planned after the manuscript is accepted.

For the current submission, the frozen material is supplied to the editors and reviewers
as **Supplement 2** accompanying the manuscript, which contains:

- generation code for the controlled image-degradation families
- frozen configurations, filename manifests and random seeds
- development-derived threshold values
- aggregate and per-class outcome tables

The manuscript itself (`Manuscript.pdf`, `Supplement1.pdf`, `Supplement2.zip`) is not
mirrored here during review.
